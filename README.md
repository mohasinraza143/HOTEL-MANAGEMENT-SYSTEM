# HOTEL-MANAGEMENT-SYSTEM
Hotel Management System is a web-based application developed using Python Django, HTML, CSS, JavaScript, and SQLite. It helps manage room bookings, customer records, check-in/check-out, billing, and hotel administration through an easy-to-use interface.

# Hotel Management System

A web-based Hotel Management System developed using **Python Django, HTML, CSS, JavaScript, and SQLite**.

## Features
- User Authentication
- Room Management
- Customer Management
- Room Booking
- Check-in & Check-out
- Billing System
- Admin Dashboard
- Responsive UI

## Tech Stack
- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite

## Purpose
This project simplifies hotel operations by providing an efficient platform to manage bookings, guests, rooms, and billing.
